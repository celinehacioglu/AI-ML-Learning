# AI-ML-Learning
My journey into artificial intelligence/machine learning.

## About This Repository

This repository documents my journey into artificial intelligence and machine learning, focusing on building intuition through visualization and practical implementation. Each notebook explores core concepts that underpin modern AI systems.

## Projects

### Linear Algebra Fundamentals
- **Day1_Basic_NumPy.ipynb**: Vector operations, matrix creation, and linear algebra basics using NumPy
  - Vector arithmetic and dot products
  - Matrix operations and transformations
  - Linear combinations and basis vectors
  
- **Day2_Matrix_Transformations.ipynb**: Understanding how matrices transform space
  - Rotation and shear transformations
  - Transformation composition
  - Visualizing geometric transformations with Matplotlib

- **Day2_3D_Rotations_Visualized.ipynb**: Three-dimensional rotations and spatial transformations
  - 3D rotation matrices (X, Y, Z axes)
  - Visualizing cube rotations in 3D space
  - Understanding transformation pipelines

- **Day2_Determinant_Visualized.ipynb**: Visualizing determinants and their geometric meaning
  - Area/volume scaling interpretation
  - Matrix invertibility
  - Geometric transformations
